# 작업 기록 템플릿

기존 AI 작업 도구가 요구사항·진행 상황·검증 근거를 파일로 읽고 이어서 작업할 수 있도록 돕는 문서 모음입니다. 별도 에이전트를 실행하거나 AI 모델을 연결하는 프로그램은 아닙니다.

## 시작하기

자료 저장소의 루트에서 다음 명령으로 **작업 공간 안의 새 폴더**에 복사합니다. 경로는 실제 작업 경로로 바꿉니다. Python 3.9 이상이면 추가 패키지 없이 실행됩니다.

```bash
python3 scripts/start_work.py --destination /path/to/task/work-notes --dry-run
python3 scripts/start_work.py --destination /path/to/task/work-notes
```

- 상위 폴더는 이미 존재해야 하며, 대상 폴더가 존재하면 복사를 거부합니다.
- 경로에 심볼릭 링크나 `..`를 넣지 않습니다. 실제 폴더의 절대 경로를 사용하면 명확합니다.
- 네트워크·AI 호출, 패키지 설치, 도구 설정 변경은 하지 않습니다.
- `AGENTS.example.md`는 참고 문서입니다. `AGENTS.md`를 만들거나 기존 지침을 덮어쓰지 않습니다.

문서만 직접 복사해도 됩니다. 먼저 `TASK.md`, `PLAN.md`, `PROGRESS.md`로 시작하고, 필요한 기록이 생기면 나머지를 사용합니다. 모든 파일을 채우거나 매번 전체를 읽힐 필요는 없습니다.

## 문서별 용도

| 문서 | 기록할 내용 | 갱신 시점 |
|---|---|---|
| [TASK.md](TASK.md) | 요구사항, 결과물, 확인 방법, 질문 | 업무 이해·요구사항 변경 |
| [PLAN.md](PLAN.md) | 최소 흐름, 구현 순서, 시간 배분 | 범위 확정·계획 변경 |
| [PROGRESS.md](PROGRESS.md) | 완료한 일, 현재 상태, 바로 다음 작업 | 의미 있는 작업 단위 완료 |
| [SOURCES.md](SOURCES.md) | 입력 파일, 기준 자료, 외부 출처 | 자료 발견·추가 |
| [DECISIONS.md](DECISIONS.md) | 확정 사항, 가정, 선택 이유 | 판단·담당자 답변 반영 |
| [VERIFICATION.md](VERIFICATION.md) | 실제 실행 결과, 실패, 미확인 항목 | 검증·수정 후 재검증 |
| [HANDOFF.md](HANDOFF.md) | 짧은 재개 요약과 읽을 파일 | 작업 중단·새 대화로 전환 |
| [SUBMISSION.md](SUBMISSION.md) | 결과물, 실행 방법, 남은 한계 | 최종 정리 |
| [AGENTS.example.md](AGENTS.example.md) | 필요한 지침을 선택하는 예시 | 지침 정리가 필요할 때 |

## AI에게 요청하기

> 작업 폴더의 기존 README와 지침을 먼저 읽고, work-notes/TASK.md에 요구사항과 확인 방법을 정리해줘. PLAN.md에 실제 입력 하나를 끝까지 처리하는 순서를 적고 구현해줘. 의미 있는 작업 단위마다 PROGRESS.md를 짧게 갱신하고, 완료를 보고하기 전에 실제 검증 결과를 VERIFICATION.md에 남겨줘. 현재 환경의 제한을 우선하고 필요한 기록만 사용해줘.

대화를 새로 시작할 때:

> 기존 지침, work-notes/HANDOFF.md와 PROGRESS.md를 읽어줘. 기록만 믿고 완료로 처리하지 말고 실제 파일과 필요한 실행 상태를 확인한 다음, 적혀 있는 다음 작업부터 이어가줘.

## 기록 원칙

- 근거가 있는 사실과 확인되지 않은 가정을 구분합니다.
- 검증하지 않은 항목은 미확인으로 남깁니다. 예시 명령이나 예상 결과를 실행 기록처럼 쓰지 않습니다.
- 원본 데이터를 보존하고, 민감한 값·인증정보를 기록에 복사하지 않습니다.
- 작성한 작업 기록과 비공개 입력 자료는 허용된 작업 공간에 보관합니다. **자료를 내려받은 공개 저장소에 작업 내용이나 결과를 동기화·게시하지 않습니다.**
- 제공된 실행 환경과 사용자 지시를 따릅니다. 이 템플릿을 이유로 AI 도구를 업데이트하거나 허용되지 않은 외부 도구를 연결하지 않습니다.
