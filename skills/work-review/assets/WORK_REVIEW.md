## 스스로 설명해 보기

아래 항목은 복습 범위입니다. 실제 평가 문항을 예측하거나 답안을 미리 작성하는 용도가 아닙니다. 해당 작업에 맞게 질문을 조정합니다.

- 어떤 업무 문제를 해결했으며, 완료를 무엇으로 판단했는가?
- 입력 하나가 결과로 바뀌는 과정을 파일이나 구성요소와 연결해 설명할 수 있는가?
- 핵심 방법을 선택한 이유와 감수한 점은 무엇인가?
- 실제로 겪은 문제의 원인을 어떻게 확인했고, 수정 효과를 어떻게 검증했는가?
- AI 결과 중 무엇을 직접 확인하거나 바꿨으며, 어떤 근거를 사용했는가?
- 아직 보장하지 못하는 부분과 다음에 검증할 것은 무엇인가?

각 질문을 실제 결정·오류·측정 사례에 맞게 구체화하고, 해당 파일·함수·검증 기록과 설명하기 어려웠던 부분을 함께 적는다.
