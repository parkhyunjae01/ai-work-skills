# 선택형 작업 지침 예시

이 파일은 자동 적용되지 않는 예시입니다. 기존 `AGENTS.md`와 제공 지침을 먼저 확인하고, 필요한 내용만 현재 작업에 맞춰 적용하세요. 기존 파일을 덮어쓰지 마세요.

- 사용자 요청과 제공 환경의 제약을 우선한다. 공개 자료를 내려받을 수 있다는 이유로 모든 도구·외부 연결이 허용된다고 가정하지 않는다.
- README·입력 자료를 읽고 목표, 필수 결과물, 완료 기준을 `TASK.md`에 정리한다. 사실과 가정을 구분한다.
- `PLAN.md`에 작은 실제 입력부터 결과까지 연결하는 순서를 적는다. 요구사항에 필요하지 않은 기능을 추가하지 않는다.
- 필요한 스킬과 참조 파일만 읽는다. AI 도구 업데이트·추가 모델 연결·전역 설정 변경을 자동으로 수행하지 않는다.
- 원본 자료와 기존 변경을 보존한다. 비공개 자료·작업 내용·인증정보를 공개 저장소나 외부 서비스에 전송하지 않는다.
- 의미 있는 작업 단위마다 `PROGRESS.md`의 현재 상태와 다음 작업을 짧게 갱신한다. 재개가 필요하면 `HANDOFF.md`에 관련 파일과 검증 근거를 남긴다.
- 완료 보고 전에 실제 실행·계산·요구사항 대조를 수행한다. `VERIFICATION.md`에 실행 결과를 기록하고 미실행·실패·통과를 구분한다.
- 검증에 실패하면 원인을 수정한 뒤 해당 항목을 다시 확인한다. 마지막에는 지정된 제출 조건과 실제 파일을 대조한다.
