# 모델 선택: Sol 중심, Luna 선택, Terra 예비

[README](../README.md) · [시작 요청](START_HERE.md)

확인일: **2026-10-30**. 비교 대상은 **GPT-6.1 Sol, GPT-5.6 Terra, GPT-6 Luna**입니다. GPT-6.1 Terra와 GPT-5.6 Terra를 혼동하지 않습니다.

## 권장 운영안

**Sol 6.1을 주 담당으로 유지하고, Luna 6은 범위가 명확한 작은 작업에만 선택적으로 사용합니다. Terra 5.6에는 필수 역할을 배정하지 않습니다.**

공식 단가·모델 용도·제한된 평가를 종합한 운영 제안입니다. 세 모델을 같은 조건에서 직접 시험한 성능 순위가 아닙니다. 실제 제공 모델·남은 시간·사용량 기준을 우선합니다.

| 모델 | 맡길 작업 | 사용할 조건 |
|---|---|---|
| Sol 6.1 | 요구사항 분석, 설계, 핵심 구현, 복잡한 디버깅, 최종 검증 | 기본 담당. 핵심 맥락을 유지 |
| Luna 6 | 지정된 문구·스타일·작은 함수 수정, 단순 변환 | 관련 파일·입출력·검사 방법이 명확하고 인계 비용이 작을 때 |
| Terra 5.6 | 예비 대안 | Sol을 쓸 수 없거나 실제 해당 작업에서 속도·품질 이점이 확인될 때 |

다른 모델을 한 번 더 호출하는 것만으로 검증이 되지는 않습니다. 실제 실행·계산 대조·요구사항 확인을 우선합니다.

## 토큰 수와 가격은 다르다

| 구분 | 의미 |
|---|---|
| 실제 사용 토큰 | 읽은 입력·대화·도구 결과, 추론과 응답에 쓰인 양 |
| 토큰 단가 | 같은 양을 처리했을 때의 비용 |
| 작업당 총비용·시간 | 반복 호출, 재시도, 수정, 검증까지 포함한 실제 소요 |
| 제공 환경의 사용량 | 계약·플랫폼에서 정하는 차감 방식. 공개 API 가격과 같다고 가정하지 않음 |

저렴한 모델이 같은 과제를 더 적은 토큰으로 해결한다는 뜻은 아닙니다. 실제 과제의 사용량·지연을 직접 측정한 결과는 없습니다.

## 공식 API 단가

**100만 토큰당 USD, Standard, 입력 272K 이하** 기준입니다. 캐시 쓰기·도구 호출·특수 처리·지역 요금 등은 별도 조건입니다.

| 모델·공식 문서 | 모델 ID | 입력 | 캐시 입력 | 출력 |
|---|---|---:|---:|---:|
| [Sol 6.1](https://developers.openai.com/api/docs/models/gpt-6.1-sol) | `gpt-6.1-sol` | $2.00 | $0.10 | $10.00 |
| [Terra 5.6](https://developers.openai.com/api/docs/models/gpt-5.6-terra) | `gpt-5.6-terra` | $2.00 | $0.20 | $12.00 |
| [Luna 6](https://developers.openai.com/api/docs/models/gpt-6-luna) | `gpt-6-luna` | $0.10 | $0.01 | $0.50 |

같은 수의 토큰을 사용한다면 Terra는 Sol 대비 입력 단가가 같고 출력 단가는 20% 높습니다. Luna의 일반 입력·출력 단가는 Sol의 1/20입니다. 이는 토큰 사용량이나 과제 통과율의 비율이 아닙니다.

**계산 예시:** 캐시 없는 입력 10,000토큰과 과금 대상 출력 2,000토큰을 동일하게 사용했다면 Sol은 $0.040, Terra는 $0.044, Luna는 $0.002입니다. 실제 작업 측정치가 아닌 단가 계산입니다.

세 모델의 API 문서상 문맥 한도는 1,050,000토큰, 최대 출력은 128,000토큰입니다. Codex나 개별 제공 환경의 한도와는 구분합니다. Sol 문서는 Codex 기본 문맥 한도를 500K로 별도 안내합니다. [Sol 모델 문서](https://developers.openai.com/api/docs/models/gpt-6.1-sol)

공식 안내도 크레딧 단가만으로 구독에 포함된 사용량 차감을 결정할 수 없다고 설명합니다. 개별 플랫폼의 한도와 가중치가 공개되지 않았다면 이 표로 남은 호출 횟수를 계산하지 않습니다. [Codex 가격 안내](https://learn.chatgpt.com/docs/pricing?surface=cli)

## 공개 평가에서 확인한 범위

OpenAI Cookbook의 **BLS 플러그인 평가** 결과입니다. 일반 코딩 벤치마크나 다른 과제의 예상 점수가 아닙니다.

| 모델 | 통과율 | 문항당 도구 호출 | 문항당 추론 토큰 |
|---|---:|---:|---:|
| Sol 6.1 | 94% | 4.02 | 19 |
| Luna 6 | 88% | 5.54 | 1,229 |
| Terra 5.6 | 미포함 | 미포함 | 미포함 |

조건: 56개 BLS 조사에 관한 108개 단일턴 질문, Codex 0.159.2·promptfoo 0.123.1, GPT-5.6 Sol 판정기, 위 표는 모델별 1회 실행. 본문은 같은 하네스에서 모델만 바꿨다고 설명하지만 production 평가의 정확한 추론 강도 값은 공개하지 않습니다. 해당 production 코드·데이터는 배포하지 않습니다.

이 사례에서 Luna는 더 많은 도구 호출과 추론 토큰을 사용했습니다. **추론 토큰은 전체 토큰이 아니므로** 전체 비용이나 일반적인 효율을 이 수치만으로 계산할 수 없습니다. [평가 원문](https://developers.openai.com/cookbook/examples/partners/harness_aware_plugin_evals/harness_aware_plugin_evals)

세 모델을 동일 조건으로 비교한 SWE-bench·Terminal-Bench 점수는 이번 공식 자료 조사에서 확인하지 못했습니다. 따라서 Terra가 모든 작업에서 열등하거나 Luna가 항상 토큰을 절약한다고 단정하지 않습니다.

Terra를 기본 배정에서 제외하는 이유는 **Sol보다 저렴하지 않고, 별도 필수 역할을 줄 만한 비교 근거가 부족하기 때문**입니다. 특정 작업의 실제 결과가 좋다면 예비 선택지로 사용할 수 있습니다.

## 추론 강도와 전환

- Sol은 `medium`을 시작점으로 삼고, 어려운 설계·원인 분석에서 필요할 때 `high`를 검토합니다. 모든 요청에 최대 강도를 고정하지 않습니다.
- Luna는 명확한 작은 작업에서 낮은 강도 또는 기본 강도로 시작하고 결과를 확인합니다. 반복 수정이 생기면 Sol로 되돌립니다.
- 실제 모델·강도는 제공 UI와 지원되는 `/status`·`/model`에서 확인합니다. 직접 전환할 수 없는 에이전트에게는 전환을 완료했다고 말하지 말고 필요한 선택을 안내하게 합니다.
- 전환 전 작업 기록에 목표·입출력·수정 파일·완료 조건·마지막 검증을 남깁니다. 독립된 새 작업에 전체 대화와 저장소를 반복 전달하지 않습니다.

지원 강도와 기본값은 각 모델 문서, 제공 환경의 동작은 해당 환경 안내를 따릅니다. 이 저장소는 모델·설정·인증을 자동 변경하지 않습니다.

4. 모델 전환보다 올바른 입력·명확한 검증 기준을 먼저 준비합니다.
5. 실제 표시되는 사용량·소요시간·재시도를 관찰해 다음 작업의 배정을 조정합니다.
