다운로드 원문은 `resources.lock.json`의 SHA-256으로 검증합니다. BMAD의 상표·기여자 고지도 원본 그대로 포함합니다. 상표 사용 권한이나 프로젝트의 공식 후원을 뜻하지 않습니다.

원문의 모델·설치·네트워크·게시 지시는 현재 작업 환경의 규정보다 우선하지 않습니다. 제공된 템플릿에서 필요한 구조만 골라 사용합니다. 이 저장소의 자체 작성 작업 관리 양식은 `templates/work-session/`에 있습니다.
